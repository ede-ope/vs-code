Ope Language Support for VS Code

This extension adds language support for the Ope Programming Language in Visual Studio Code, making it easier to write, read, and manage Ope source files.

✨ Features

Syntax highlighting for Ope source files

Basic IntelliSense (keywords, functions, and types)

Code snippets for common Ope patterns

Automatic indentation and formatting rules

Comment toggling support

File association for .ope and related extensions

📦 Installation

Open Visual Studio Code.

Go to the Extensions view (Ctrl+Shift+X or Cmd+Shift+X on macOS).

Search for Ope Language Support.

Click Install.

Or, if you have the .vsix package:

code --install-extension ope-language-support.vsix

🚀 Usage

Open any .ope file in VS Code.

Ope syntax highlighting and editor features will activate automatically.

Use snippets by typing keywords and pressing Tab.

🛠 Development

To work on this extension locally:

git clone https://github.com/your-username/ope-vscode-extension.git
cd ope-vscode-extension
npm install
code .

Make changes in syntaxes/ and language-configuration.json to improve support.
