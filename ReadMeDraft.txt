Kui Language Support for VS Code

This extension adds language support for the Kui Programming Language in Visual Studio Code, making it easier to write, read, and manage Kui source files.

✨ Features

Syntax highlighting for Kui source files

Basic IntelliSense (keywords, functions, and types)

Code snippets for common Kui patterns

Automatic indentation and formatting rules

Comment toggling support

File association for .kui and related extensions

📦 Installation

Open Visual Studio Code.

Go to the Extensions view (Ctrl+Shift+X or Cmd+Shift+X on macOS).

Search for Kui Language Support.

Click Install.

Or, if you have the .vsix package:

code --install-extension kui-language-support.vsix

🚀 Usage

Open any .kui file in VS Code.

Kui syntax highlighting and editor features will activate automatically.

Use snippets by typing keywords and pressing Tab.

🛠 Development

To work on this extension locally:

git clone https://github.com/your-username/kui-vscode-extension.git
cd kui-vscode-extension
npm install
code .


Press F5 to launch a new VS Code window with the extension loaded.

Make changes in syntaxes/ and language-configuration.json to improve support.
